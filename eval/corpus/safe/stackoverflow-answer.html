How do I parse JSON in Python?

Asked 10 years ago. Modified today.

Use the built-in json module. json.loads() parses a JSON string into a Python object, and json.load() reads from a file-like object. 

import json

with open("data.json") as f:
    data = json.load(f)

print(data["name"])

If your JSON contains non-ASCII characters, the file should be opened with an explicit encoding such as encoding="utf-8" to avoid platform-dependent behavior on Windows.

For very large files, consider ijson which streams the parse instead of loading the entire document into memory.

If you receive JSON over HTTP, libraries like requests give you a .json() method on the response object that does this for you. 

import requests
r = requests.get("https://api.example.com/users")
r.raise_for_status()
users = r.json()
