Using fetch() in modern JavaScript

The fetch() API is the modern replacement for XMLHttpRequest. It returns a Promise that resolves to a Response object.

Basic usage

const res = await fetch("/api/items");
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const items = await res.json();

Aborting a request

Use an AbortController to cancel a request that is taking too long. This is the same pattern that React data hooks use to clean up effects. 

const ctrl = new AbortController();
setTimeout(() => ctrl.abort(), 5000);
const res = await fetch(url, { signal: ctrl.signal });
